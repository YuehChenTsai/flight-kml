輸入飛機的機身編號（如 B-18317、JA838A、9V-SWA）及日期，系統會透過 globe_history 端點取得該日完整軌跡。 若不知道 tail number，請使用「航班查詢」分頁。
輸入 ICAO 航班呼號（例如華航 CI052 → CAL052、立榮 B7-8607 → UIA8607）。
系統會先嘗試從即時 API 取得對應飛機 hex，若飛機不在飛行中，則需要手動輸入 tail number。
hexdb.io 可查詢 tail → hex 對照。
OpenSky 提供最近 30 天的歷史軌跡，但 API 可能不穩定（請看健康指示燈）。
使用前請先確認 OpenSky 狀態為綠燈。查詢較慢，請耐心等候。
